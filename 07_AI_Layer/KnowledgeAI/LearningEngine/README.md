# Learning Engine
Status: CANONICAL

# Purpose
LearningEngine GoldBot KnowledgeAI ichidagi Canonical Self-Learning moduli hisoblanadi.
Uning asosiy vazifasi ValidationEngine tomonidan tasdiqlangan yangi bilimlarni o'rganish, mavjud bilimlarni yangilash va AI tajribasini boyitishdir.
LearningEngine mustaqil ravishda bilim yaratmaydi.
LearningEngine Validation bajarmaydi.
LearningEngine External AI chaqirmaydi.
