# Purpose
PersonalAI GoldBot AI Layer ichidagi foydalanuvchi bilan ishlovchi Canonical Personal Intelligence moduli hisoblanadi.
Uning asosiy vazifasi foydalanuvchi bilan tabiiy muloqot qilish, shaxsiy xotirani ishlatish, foydalanuvchi odatlarini o'rganish va yagona Personal AI tajribasini taqdim etishdir.
PersonalAI GoldBot ichidagi yagona Personal Intelligence hisoblanadi.
