# AI Coordinator
Status: CANONICAL
---
# Purpose
AICoordinator GoldBot AI Layer ichidagi Canonical AI Orchestration moduli hisoblanadi.
Uning asosiy vazifasi AI Layer ichidagi barcha AI modullarini yagona Pipeline sifatida boshqarish va ularning ishlash ketma-ketligini nazorat qilishdir.
AICoordinator AI Analysis bajarmaydi.
AICoordinator Decision qabul qilmaydi.
AICoordinator Signal yaratmaydi.
AICoordinator faqat AI Workflow Orchestration bilan shug'ullanadi.
---

# Golden Rules
1. Kerak bo'lmagan AI modullar ishga tushirilmaydi.
2. AI modullar parallel ishlashi mumkin.
3. Barcha Context yagona formatga o'tkaziladi.

5. Circular Dependency qat'iyan taqiqlanadi.
