# Knowledge Manager
Status: CANONICAL
---
# Purpose
KnowledgeManager GoldBot KnowledgeAI ichidagi Canonical Knowledge Lifecycle moduli hisoblanadi.
Uning asosiy vazifasi AI bilimlarini yaratish, yangilash, versiyalash, tasniflash va boshqarishdir.
KnowledgeManager bilimning o'zini boshqaradi.
KnowledgeManager Memory saqlamaydi.
KnowledgeManager AI Analysis bajarmaydi.
KnowledgeManager Provider chaqirmaydi.
---
# Objective
KnowledgeManager quyidagi vazifalarni bajaradi.
• Knowledge Registration
• Knowledge Classification
