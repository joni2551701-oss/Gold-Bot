# DD-002 — Canonical Source

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1 (FROZEN).
**Context**: With the Repository Audit accepted (DD-001), the Director
formally designates which branch is the authoritative implementation of
GoldBot v1, removing any remaining ambiguity between `main` and the
production branch.

## Decision

The production branch —

```
claude/code-analysis-optimization-pwfo3q
```

— **is GoldBot v1.** It is hereby the **reference implementation**: the
canonical source from which Migration content flows into `main`.

## Why

The Repository Audit established (and independent verification
confirmed) that production is **171 commits ahead** of `main`, carries
the evolved, clean-named modules, and holds the real v1 content, while
`main` holds only 5 divergent, pre-migration commits and 9 U+2060
corrupted filenames. Naming the canonical source explicitly prevents
any future work from treating stale `main` as the source of truth.

## Status

**Approved — binding for GoldBot v1.** All Migration content is drawn
*from* this branch; `main` is reconciled *to* it (see DD-003).

## Applies to

Every Migration, reconciliation, or release action for GoldBot v1;
any determination of "current correct behavior" during Recovery
verification and Migration.
