# DD-027 — Extended Candle Memory Model

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1. **Phase**: GoldBot v1.1 Phase 1 — Market Data Foundation.
**Context**: The initial design stored mainly OHLC + status in Memory.

## Decision

Memory stores more than candles. **Per candle, per timeframe**, it keeps:
OHLC, timestamp, candle status, metadata, **candle_id**, **sequence
number**, **source**, **last update time**, **session**, **trading day**.

## Why

These fields make replay (DD-033), chart diffing (DD-029) and AI context
deterministic and reproducible — a bare OHLC series cannot support replay,
stable identity, or provenance.

## Status

**Approved — binding for the Market Data Foundation.** Reflected in the
architecture document (§4 (Candle record model)).

## Applies to

The GoldBot v1.1 Market Data Foundation (`data/` layer) and every future
component that reads market data through it.
