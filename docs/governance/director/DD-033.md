# DD-033 — Replay Mode

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1. **Phase**: GoldBot v1.1 Phase 1 — Market Data Foundation.
**Context**: Memory was designed for live data only.

## Decision

Memory must support two modes — **LIVE** and **REPLAY**. AI and Chart
must be able to consume replay identically to live.

## Why

Replay (driven by sequence numbers, DD-027) enables backtest-style
analysis and visual review with no code fork on the consumer side — the
same reader and events drive both modes.

## Status

**Approved — binding for the Market Data Foundation.** Reflected in the
architecture document (§9 (Replay Mode)).

## Applies to

The GoldBot v1.1 Market Data Foundation (`data/` layer) and every future
component that reads market data through it.
