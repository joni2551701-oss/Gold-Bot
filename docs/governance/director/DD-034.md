# DD-034 — Snapshot API

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1. **Phase**: GoldBot v1.1 Phase 1 — Market Data Foundation.
**Context**: There was no first-class way to capture Memory state at an instant.

## Decision

Memory must provide `snapshot()` at any time, returning an immutable
point-in-time copy. Used for debug, AI, export, mobile sync, and the future
API.

## Why

A serializable value-object snapshot is what safely crosses process and
network boundaries (mobile/API) and gives AI/debug a stable frame.

## Status

**Approved — binding for the Market Data Foundation.** Reflected in the
architecture document (§8 (Snapshot API)).

## Applies to

The GoldBot v1.1 Market Data Foundation (`data/` layer) and every future
component that reads market data through it.
