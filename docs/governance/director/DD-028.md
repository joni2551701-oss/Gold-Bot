# DD-028 — Memory Event System

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1. **Phase**: GoldBot v1.1 Phase 1 — Market Data Foundation.
**Context**: The initial design exposed reads; consumers would have polled for changes.

## Decision

A **Memory Event System** is added. Every candle transition emits an
event — `OnNewCandle`, `OnCandleUpdate`, `OnCandleClose`. Future consumers
(Chart, AI, Telegram, Desktop) **subscribe** to these events. **Polling is
not used.**

## Why

Push-based events decouple producers from consumers and remove polling
latency/waste; multiple platforms react to the same Memory transitions
without touching internals.

## Status

**Approved — binding for the Market Data Foundation.** Reflected in the
architecture document (§6 (Memory Event Bus)).

## Applies to

The GoldBot v1.1 Market Data Foundation (`data/` layer) and every future
component that reads market data through it.
