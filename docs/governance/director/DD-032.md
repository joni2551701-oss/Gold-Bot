# DD-032 — Chart Support Expansion

**Type**: Director Decision Record (Director-issued, binding).
**Governance**: v1.1. **Phase**: GoldBot v1.1 Phase 1 — Market Data Foundation.
**Context**: Chart integration was sketched generically.

## Decision

Chart support covers **TradingView-style, Lightweight Charts, Custom
charts, and Replay** — all rendering **from Memory**. A chart **never**
calls the API.

## Why

Standardizing all chart variants on Memory (via MemoryReader + events)
keeps the provider out of the UI path and lets many charts share one
Memory.

## Status

**Approved — binding for the Market Data Foundation.** Reflected in the
architecture document (§18 (Chart Integration)).

## Applies to

The GoldBot v1.1 Market Data Foundation (`data/` layer) and every future
component that reads market data through it.
