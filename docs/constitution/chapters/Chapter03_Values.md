## Executive Summary

Chapter 01 fixed the vision and Chapter 02 fixed the mission. Chapter 03 fixes
the **values** — the shared convictions that decide *how* the mission is pursued
when a choice must be made. Values are the tie-breakers of the Constitution: when
two acceptable options compete, the values state which one GoldBot chooses.

GoldBot's values place the integrity of the foundation, the safety of the user,
and the auditability of decisions above speed, novelty, and convenience. This
chapter states those values across the domains where choices arise —
engineering, artificial intelligence, the user relationship, and day-to-day
decision-making — and defines what it means to comply with them.

## 1. Values Statement

GoldBot values a **stable foundation, a protected user, and an auditable
history** above the speed of any single delivery. Values exist to resolve
conflict: whenever a decision could be made in more than one acceptable way, the
values determine which way GoldBot goes.

## 2. Core Values

- **Integrity of the foundation.** The Core and its boundaries are protected
  before any feature. Where feature progress and foundation integrity conflict,
  the foundation prevails.
- **Safety by construction.** Protection is built into the architecture, not
  layered on by careful operation.
- **Auditability.** Consequential decisions and changes leave a traceable record;
  nothing consequential is silent.
- **Honesty.** The true state of the system — including its limitations — is
  reported plainly.
- **Durability.** Choices are made for the long horizon, favoring what will still
  be sound years from now.

## 3. Engineering Values

- **Foundation first, extension after.** Build the base carefully once; grow it by
  addition, not by rewrite.
- **Reuse before creation.** The preferred component is the one that already exists
  and already works; new components are justified only when none can serve or be
  extended.
- **Clarity over cleverness.** Code and documents are written to be understood
  later by someone who was not present when they were written.
- **Documentation before code.** Intent and architecture are recorded before
  implementation and kept current.
- **Correctness before speed.** A change is not done until it is validated; a fast
  change that is not verified is not valued.

## 4. AI Values

- **Advisory humility.** The AI layer advises; it never decides, executes, or
  touches the controls. It is valued for the quality of its input, never for
  autonomy.
- **Provider neutrality.** The system is valued for being independent of any single
  AI provider, so intelligence can improve without disturbing the Core.
- **Traceable reasoning.** Advisory output follows a defined path, so its role in a
  decision can be examined.
- **Restraint.** The AI layer is valued as much for what it declines to do as for
  what it produces.

## 5. User Values

- **The user stays in control.** GoldBot is valued for keeping the human in the
  loop for consequential action, not for removing them.
- **Protection without dependence on vigilance.** The user is safe because of what
  the system cannot do, not only because of how carefully it is run.
- **Trustworthy information.** What the user is shown has a traceable origin.
- **Stability of experience.** The behavior the user relies on is not silently
  changed by later additions.

## 6. Decision Values

- **No silent decisions.** A choice the executor cannot resolve from the brief is
  returned for a ruling, not made quietly.
- **Reversible over irreversible.** Where outcomes are uncertain, the option that
  is easier to undo is preferred.
- **Boundaries are not traded away.** No decision is valued that weakens the single
  entry point, the platform independence, or the safety guarantees.
- **Recorded rationale.** A decision worth making is worth recording, with its
  reasoning and its approval.

## 7. Long-Term Values

- **Amend rarely, extend routinely.** The governing documents are valued for their
  stability; growth is normally addition, not amendment.
- **Constancy of guarantees.** The commitments owed to the user do not weaken as
  the system grows.
- **Institutional memory.** Lessons and decisions are preserved so the system does
  not relearn the same lessons.
- **Compounding foundations.** Each carefully built layer makes the next one
  cheaper and safer; this compounding is valued over short-term shortcuts.

## 8. Value Compliance

Compliance with these values is demonstrated, not asserted:

- A decision that conflicts with a stated value is either avoided or escalated for
  a ruling, and the reason is recorded.
- Foundation integrity, user protection, and auditability are treated as
  non-negotiable inputs to every review.
- Where two options are both acceptable, the record shows the values were used to
  choose between them.
- A change that would erode a boundary is not accepted on the grounds of speed or
  convenience.

Values are binding in the same sense as the rest of the Constitution: they are the
standard a review measures against, and a proposal that violates them is not
approved merely because it is otherwise attractive.
