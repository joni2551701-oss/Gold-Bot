# issues/

A bug found during Platform (or Core) work, filed as a ticket using
`docs/PLATFORM_BUG_REPORT_STANDARD.md`'s exact format — never just
"bug fixed" with no detail, per the Director's explicit instruction.

## Naming

`ISSUE-XXXX.md`, sequential, zero-padded to 4 digits.

## Template

See `TEMPLATE.md` in this folder — it mirrors
`docs/PLATFORM_BUG_REPORT_STANDARD.md` field-for-field. That document
is the canonical definition of each field; this template exists so
filing an issue doesn't require opening a second file.
