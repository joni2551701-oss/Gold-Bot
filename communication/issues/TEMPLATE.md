# ISSUE-XXXX

**Module**: the affected module/file

## Problem

What is observed, concretely (an input, an action, the actual output).

## Root Cause

The actual mechanism producing the wrong behavior — not a guess, the
verified cause.

## Current Code

The relevant existing code (file path + line range, or a short quote).

## Correct Architecture

What the code *should* do, in terms of this repo's own architecture
rules (`docs/ARCHITECTURE_RULES.md`, `docs/PLATFORM_DEPENDENCY_MAP.md`,
or the Constitution, whichever governs the affected area).

## Correct Code

The proposed fix (a diff, or a description precise enough to implement
from).

## Regression Risk

What could break if this fix is applied — which tests cover it, what's
untested.

## Tests

Which existing tests cover this area; which new test(s) this fix adds
or should add.

## Status

Open / In Progress / Fixed / Won't Fix (with reason)
