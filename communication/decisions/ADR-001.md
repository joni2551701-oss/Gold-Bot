# ADR-001 — GoldBot Platform is not built around Telegram Bot

**Type**: Architecture Decision Record (Director-issued, binding,
permanent — see `communication/decisions/README.md` for how this
differs from `DEC-XXXX.md`/`PROPOSED-DECISION-XXXX.md`).
**Formalized as**: `docs/constitution/CONSTITUTION.md` Article 13
(Future First Principle).
**Full ledger entry**: `docs/changelog/DECISION_LOG.md`.

## Decision

GoldBot Platform is architected as:

```
Platform Core
      ↓
Shared Platform Layer
      ↓
Telegram Bot | Telegram Mini App | Android | iOS | Desktop
```

Telegram is one client among five equals — not the foundation the
other four are bolted onto later.

**Consequence — Universal UI Abstraction rule**: no Platform component
is ever written as

```
Telegram Callback → Business Logic
```

It is always

```
Platform UI → Navigation Layer → Application Layer → Business Logic
```

## Why

If Navigation (or any other Platform component) is designed
Telegram-first, every one of the other four platforms requires
rewriting it later. This decision accepts the cost of designing for
five platforms today — four of which have zero code — to avoid that
rework.
