# decisions/

A cross-role decision ticket — a specific Core↔Platform boundary
question resolved during handoff (e.g. "should the Signal History API
return X shape or Y shape?"). This is a **working ticket**, not the
permanent record: once a decision here is load-bearing, it is also
recorded in `docs/changelog/DECISION_LOG.md` (Constitution Article 8's
permanent ledger). This folder does not replace that ledger.

## Naming

`DEC-XXXX.md`, sequential, zero-padded to 4 digits.

## Template

See `TEMPLATE.md` in this folder.

## Related

  decision here graduates into.
