# notifications/

One-way heads-up between Core and Platform — no response expected,
unlike `requests/`. Use this for "you should know this happened," not
"I need something from you."

## Naming

`NOTE-XXXX.md`, sequential, zero-padded to 4 digits.

## Template

See `TEMPLATE.md` in this folder.
