# technical_debt/

A debt ticket raised during Core↔Platform handoff. This is a
**working ticket**, not the permanent ledger:
`docs/TECHNICAL_DEBT.md` (established the prior phase) remains the
running register of known, deliberately-unfixed items. Once a ticket
here is accepted as such by the Director, it is folded into that
ledger; this folder does not duplicate or replace it.

## Naming

`TD-XXXX.md`, sequential, zero-padded to 4 digits.
